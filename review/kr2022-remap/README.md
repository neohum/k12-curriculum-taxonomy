# 손작성 성취기준 자동 재매핑 (검토용, 사람 미확인)

이 폴더의 파일은 **공식 매핑이 아닙니다.** 저장소에 있던 손작성 성취기준을 교육부 고시 원문 성취기준(`data/kr-2022/standards.json`)에 문자 bigram 유사도로 자동 연결해 본 결과이고, 사람이 확인하지 않았습니다(`humanVerified: false`). 앱 코드는 이 파일을 쓰지 않습니다.

다시 만들기: `node scripts/kr2022/remap-handwritten.mjs`

## 상태의 뜻

| 상태 | 건수 | 뜻 |
|---|---:|---|
| matched | 73 | 같은 교과·학년군 안에서 1등 점수 0.5 이상, 2등과 0.1 이상 차이. **검토 후보일 뿐 맞는 매핑이라는 뜻이 아닙니다.** |
| ambiguous | 14 | 1등과 2등 차이가 0.1 미만 |
| unmapped | 246 | 1등 점수 0.5 미만(후보 있음 160, 0.2 이상 후보 없음 86) |

- 임계값(0.5 / 0.1 / 0.2 / 0.75 / 0.2)은 공식 데이터를 보기 전에 정했고, 결과를 보고 바꾸지 않았습니다.
- matched 73건 중 57건(78%)은 점수 0.75 미만, 2등과 차이 0.2 미만, 또는 여러 손작성 항목이 같은 공식 성취기준을 가리켜 검토 큐에 들어 있습니다. 검토 사유 없이 남은 matched는 16건뿐입니다.
- 교차 리뷰에서 matched 표본 20건 중 일부가 여러 성취기준을 합친 손작성 문장을 하나로 연결한 경우로 지적됐습니다. matched도 반드시 사람이 확인해야 합니다.

## 검토 큐 231건 구성 (`handwritten-remap.review.json`)

| 상태 | 사유 | 건수 |
|---|---|---:|
| unmapped | near-miss (0.2 이상 후보 있음) | 160 |
| ambiguous | top-two-within-margin | 14 |
| matched | low-score / narrow-margin / shared-target 중 하나 이상 | 57 |

검토 큐에 없는 항목:
- unmapped 중 0.2 이상 후보가 없는 86건: 비교할 공식 성취기준 후보가 없어 큐에서 뺐습니다. 이 항목들은 손작성 문장을 지우거나 새로 연결할지 사람이 정해야 합니다.
- 검토 사유가 없는 matched 16건.

## unmapped가 많은 이유

손작성 문장이 원문과 크게 다릅니다. 코드가 공식 코드와 같은 항목도 문장은 다른 성취기준 내용인 경우가 많습니다(예: 손작성 `[2수01-10]`은 곱셈구구 내용인데, 공식 `[2수01-10]`은 곱셈의 의미 이해).

## addedByUs

오개념·교구·피아제 단계·키워드·Marble 토픽 매핑은 고시 원문이 아니라 이 저장소가 덧붙인 내용입니다. 공식 성취기준 데이터(`data/kr-2022/`)에 합치지 않았고, 사람이 매핑을 확인한 뒤에만 옮길 수 있습니다.

## 선수관계 그래프를 커밋하지 않은 이유

`node scripts/kr2022/build-prerequisites.mjs`로 만들면 간선 14,990개(hard 5 / soft 14,985)가 나옵니다. 이번에는 결과를 커밋하지 않았습니다.

- same-domain-sequence 14,979개: 앞뒤 학년군의 모든 쌍을 잇기 때문에, 위계 정보라기보다 영역 묶음에 가깝습니다.
- marble-dependency 14개: 손작성 어댑터의 Marble 토픽 매핑이 거칠어 `[9수01-06] → [4수01-09]`처럼 중학교 성취기준이 초등의 선수학습이 되는 간선과 `[4수01-13] ↔ [4수01-14]` 순환이 생깁니다.
- 선수관계는 교사가 직접 넣는 `data/kr-2022/prerequisites.manual.json`부터 채우고, 자동 근거 규칙은 그다음에 정합니다.
