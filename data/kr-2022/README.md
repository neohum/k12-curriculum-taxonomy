# 2022 개정 교육과정 성취기준 (고시 원문 추출본)

`standards.json`은 교육부 고시 제2022-33호(2022.12.22.) 「초·중등학교 교육과정」의 별책 5~18, 20~22에서 성취기준 코드와 문장을 뽑은 데이터입니다. 성취기준은 4,296개입니다.

| 파일 | 내용 |
|---|---|
| `standards.json` | 성취기준 목록. 형식은 아래 "필드" 절에 있습니다. |
| `sources.json` | 원문 파일(HWP·PDF)의 NCIC 다운로드 URL, 받은 시각, sha256. 원본 파일은 저장소에 넣지 않습니다. |
| `extraction-report.json` | 별책별 추출 개수, 원문에서 같은 코드가 겹치는 경우(`codeConflicts`), 해설에만 나오는 코드 오기(`unextractedCodes`) |
| `prerequisites.manual.json` | 사람이 직접 넣는 선수관계. `from`과 `to`에는 `id`를 씁니다. |

## 무엇이 원문 그대로이고 무엇이 붙인 값인가

`standards.json` 최상위의 `fieldProvenance`에 필드마다 값이 어디서 왔는지 적혀 있습니다. 자세한 설명은 `fieldProvenanceNotes`에 있습니다.

| 필드 | 출처 | 설명 |
|---|---|---|
| `text` | **verbatim** | HWP 문단 텍스트를 그대로 썼고 앞뒤 공백만 지웠습니다. 수식은 아래 예외를 보세요. |
| `code` | **verbatim** | 원문 코드 그대로입니다. 바꾼 것은 3건뿐입니다. `[4사01-01]`, `[4사01-02]`는 원문의 en dash "–"를 "-"로 바꿨습니다. `[12연몸02-04]`는 원문에 여는 대괄호가 빠져 있어 코드에만 보충했습니다. 세 건 모두 `parseWarning`에 원래 표기를 남겼습니다. |
| `id` | derived-from-structure | `b<별책 번호>:<code>` 형식입니다. 같은 별책에서 같은 코드가 다시 나오면 `#2`를 붙입니다. 원문에는 없는 식별자입니다. |
| `subject` | derived-from-structure | 별책 이름입니다. 별책 10·15·18처럼 한 별책에 교과가 여럿이면 코드 약호로 나눴습니다. |
| `course` | derived-from-structure | 초·중학교는 교과명 또는 코드 약호 대응표에서 정했습니다. 고등학교는 "1. 성격 및 목표" 앞의 과목 제목과 `[과목명]` 소제목에서 추정했습니다. |
| `schoolLevel` | derived-from-code | 코드 앞 숫자로 정했습니다. 2·4·6은 ES, 9는 MS, 10·12는 HS입니다. |
| `gradeBand` | derived-from-code | 코드 앞 숫자로 정했습니다. 10은 "고등학교 공통 과목", 12는 "고등학교 선택 과목"입니다. |
| `domain` | derived-from-structure | 목록 위의 "(n) 영역명" 소제목입니다. 원문에 소제목이 없는 과목은 `null`입니다. |
| `source.page` | derived-from-structure | 문장을 PDF 텍스트와 대조해 찾은 PDF 파일의 실제 쪽 순서(1부터)입니다. 인쇄된 쪽 번호와 다를 수 있습니다. |

### 수식
원문의 수식은 한컴 수식 개체로만 들어 있습니다. 처리 방식은 둘입니다.

- 한 글자 변수(`x`, `y=x`, `n`)와 `times`→×, `div`→÷는 일반 글자로 옮겼습니다.
- 분수·루트·Σ 같은 나머지는 `{{EQ:한컴 수식 스크립트}}`로 그대로 남겼습니다.

두 경우 모두 `parseWarning`에 적었습니다. 수식이 들어간 항목은 18개입니다.

## 원문에서 코드가 겹치는 경우 (12개 코드)

`code`는 고유하지 않습니다. 항목을 구별할 때는 `id`를 쓰세요. 겹치는 코드의 항목에는 `codeConflict`가 붙습니다.

- `cross-subject`: 서로 다른 과목이 같은 코드를 씁니다.
  - `[12심독01-01]`~`[12심독02-04]` 8개: 별책 14 「심화 영어 독해와 작문」과 별책 16 「심화 독일어」
  - `[12스문01-01]`~`[12스문01-03]` 3개: 별책 11 「스포츠 문화」와 별책 16 「스페인어권 문화」
- `same-book-duplicate`: 별책 21 성취기준 목록에 `[12스경02-02]`가 두 번 나오고 문장이 다릅니다. 해설에서는 두 번째 문장을 `[12스경02-03]`이라고 부릅니다. 원문 오기로 보이지만 코드는 고치지 않았고, 두 번째 항목의 `id`는 `b21:[12스경02-02]#2`입니다.

## 재현

```
node scripts/kr2022/extract-standards.mjs --raw-dir <sources.json의 파일을 받아 둔 폴더>
```

- `pdftotext`(poppler)가 필요합니다.
- 받아 둔 파일의 sha256이 `sources.json`과 다르면 멈춥니다.
- 원본 파일이 있을 때 `KR2022_RAW_DIR=<폴더> npm test`를 실행하면, 전체를 다시 추출한 결과가 커밋된 `standards.json`과 바이트 단위로 같은지 확인합니다.

## 저작권과 이용 조건

- 고시 원문(별책 포함)은 저작권법 제7조 제2호(국가 또는 지방자치단체의 고시)에 따라 보호받지 못하는 저작물이라고 보는 것이 이 저장소의 판단입니다.
- 다만 원문을 받은 국가교육과정정보센터(NCIC) 게시물에는 **공공누리 제2유형(출처표시·상업적 이용 금지)** 표시가 붙어 있습니다.
- 해설서·평가기준 등 고시가 아닌 자료는 포함하지 않았습니다.
- 이 설명은 **법률 자문이 아닙니다.** 상업적으로 이용하기 전에는 권리자(교육부·NCIC)에게 이용 조건을 확인하세요.

## 범위 밖

- 넣지 않은 별책: 19(고등 교양 — 국가교육위원회 고시 제2024-3호 수정본만 공개됨), 23~39(전문 교과), 40(창의적 체험활동), 41(한국어 교육과정 — 제2017-131호)
- 2026.01 일부개정 고시 판본은 반영하지 않았습니다.
- NCIC는 일부 별책 파일을 고시일 뒤에 다시 올렸습니다(국어·도덕 2026-11, 실과/정보 2026-08, 사회 2023-11 등). 표지에는 모두 「교육부 고시 제2022-33호」라고 되어 있지만, 일부개정 내용이 섞였는지는 확인하지 않았습니다.
